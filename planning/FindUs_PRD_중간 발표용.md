# FindUs PRD — 요구사항 정의서

## 문서 개요

- **요구사항 수:** 19개
- **구성:** 핵심 요구사항, 완료 기준, 미확정 / 검토 필요 사항
- **참고:** 미확정 사항은 확정된 정책이 아닙니다.

## 서비스 소개 (INTR)

### INTR-001 — 서비스 소개

- **관련 화면:** FindUs 소개
- **핵심 요구사항:** 서비스 목적·이용 흐름·AI 한계·안전Dream 출처 및 공개정보 활용 범위를 안내
- **완료 기준:** 서비스 이용 방법과 AI 결과의 참고용 성격, 공식 신원 확인 주체를 확인 가능

## 실종 정보 (SEAR)

### SEAR-001 — 실종 정보 등록

- **관련 화면:** 시스템 / 운영자 처리
- **핵심 요구사항:** 안전Dream 신규 사건을 식별값으로 등록하고 공개·장기 실종아동 조건 확인
- **완료 기준:** 중복 없이 대상 사건만 조회 화면에 표시

### SEAR-002 — 실종 정보 조회

- **관련 화면:** 실종아동 찾기 / 상세
- **핵심 요구사항:** 목록·조건 검색·상세 조회 및 원본/예상 사진 비교·지도·링크 공유 제공
- **완료 기준:** 검색·상세·공유 가능; 결과 없음·조회 실패·이미지 없음·공개 종료 구분 안내

### SEAR-003 — 실종 정보 수정

- **관련 화면:** 시스템 / 운영자 처리
- **핵심 요구사항:** 공개 원본 변경·확인된 정정만 반영; 사진·나이 변경 시 AI 이미지 갱신 연계
- **완료 기준:** 허용된 변경만 반영; 시민 임의 수정 차단; 필요한 이미지 갱신

### SEAR-004 — 실종 정보 삭제

- **관련 화면:** 시스템 / 운영자 처리
- **핵심 요구사항:** 운영 정책에 따라 자료 삭제; 공개 종료 시 사진·예상 이미지 삭제
- **완료 기준:** 삭제 자료 조회·직접 접근 차단; 다른 사건 자료 보존
- **미확정 / 검토 필요:** 사건 정보 보관 범위 미정

## 게시판 (BOAR)

### BOAR-001 — 게시글 작성

- **관련 화면:** 게시판 / 작성
- **핵심 요구사항:** 작성 권한 보유자가 제목·내용 입력 후 등록
- **완료 기준:** 필수값 검증 후 등록; 무권한 작성 차단
- **미확정 / 검토 필요:** 작성 권한·첨부파일·익명 여부 미정

### BOAR-002 — 게시글 조회

- **관련 화면:** 게시판 / 상세
- **핵심 요구사항:** 게시글 목록·검색·페이지 이동·상세 조회 제공
- **완료 기준:** 공개 범위 내 조회; 검색 결과 없음·삭제 글 접근 안내
- **미확정 / 검토 필요:** 공개 범위·검색 조건 미정

### BOAR-003 — 게시글 수정

- **관련 화면:** 게시판 / 수정
- **핵심 요구사항:** 수정 권한 보유자가 제목·내용 변경
- **완료 기준:** 권한 있는 사용자만 수정; 변경 사항 상세 반영
- **미확정 / 검토 필요:** 작성자·관리자 수정 범위 미정

### BOAR-004 — 게시글 삭제

- **관련 화면:** 게시판 / 상세
- **핵심 요구사항:** 권한 확인 및 삭제 확인 후 게시글 삭제
- **완료 기준:** 삭제 글 일반 조회 제외; 무권한 삭제 차단
- **미확정 / 검토 필요:** 관리자 삭제 범위·삭제/비공개 방식 미정

## 회원 (MEMB)

### MEMB-001 — 회원 가입

- **관련 화면:** 회원 가입
- **핵심 요구사항:** 확정된 가입 방식으로 회원 생성
- **완료 기준:** 유효 정보로 가입 성공; 중복·오입력 안내
- **미확정 / 검토 필요:** 필수 정보·중복 기준·인증 방식 미정

### MEMB-002 — 회원 정보 조회

- **관련 화면:** 회원 정보
- **핵심 요구사항:** 로그인 회원에게 본인 정보 조회 제공
- **완료 기준:** 본인 정보만 조회; 타 회원 임의 접근 차단
- **미확정 / 검토 필요:** 관리자 조회 범위 미정

### MEMB-003 — 회원 정보 수정

- **관련 화면:** 회원 정보
- **핵심 요구사항:** 회원이 허용된 본인 정보 항목 변경
- **완료 기준:** 허용 항목만 저장·반영; 타 회원 수정 차단
- **미확정 / 검토 필요:** 수정 가능 항목·재인증 조건 미정

### MEMB-004 — 회원 탈퇴

- **관련 화면:** 회원 정보
- **핵심 요구사항:** 본인 확인·탈퇴 확인 후 계정 탈퇴 처리
- **완료 기준:** 탈퇴 계정 로그인·회원 기능 차단; 연관 정보 정책대로 처리
- **미확정 / 검토 필요:** 게시글 등 연관 정보 보관·삭제 정책 미정

### MEMB-005 — 로그인·로그아웃

- **관련 화면:** 로그인 / 공통
- **핵심 요구사항:** 회원 인증 및 로그인 상태 종료 제공
- **완료 기준:** 인증 성공·실패 구분; 로그아웃 후 회원 기능 접근 차단
- **미확정 / 검토 필요:** 인증 방식·로그인 유지 기간 미정

## AI 예상 이미지 (GENE)

### GENE-001 — AI 현재 예상 모습 생성

- **관련 화면:** AI 처리 / 상세
- **핵심 요구사항:** 원본 사진·당시/현재 나이 기반 예상 이미지 사전 생성; 워터마크·갱신·실패 처리
- **완료 기준:** 사건별 이미지 연결·AI 추정 표시; 실패 시 원본 유지; 입력 변경 시 갱신 가능
- **미확정 / 검토 필요:** 모델·생성 기준 검증 후 확정

## 실종 정보 운영 (MANA)

### MANA-001 — 실종 정보 동기화

- **관련 화면:** 시스템
- **핵심 요구사항:** 매일 새벽 안전Dream 전체 목록 대조; 신규·변경·공개 종료 후보 확인; 중복·호출 제한·인증키 보호
- **완료 기준:** 정상 대조 결과를 등록·수정·종료에 반영; 실패 시 기존 정보 유지·불완전 목록 배제

### MANA-002 — 공개 상태 및 정정 관리

- **관련 화면:** 시스템 / 운영자 처리
- **핵심 요구사항:** 정상 대조에서 사라진 사건 즉시 비공개; 다음 정상 대조에도 없으면 이미지 삭제; 정정은 운영자 확인 후 반영; 수집 급감 시 자동 처리 중단
- **완료 기준:** 비공개 사건 목록·상세·직접 링크 차단; 확인된 정정만 반영; 동기화 이상 시 일괄 삭제 방지

## 공식기관 제보 (REPO)

### REPO-001 — 공식기관 제보 안내 및 연결

- **관련 화면:** 제보 안내
- **핵심 요구사항:** 목격 정보 가이드·AI 주의사항·182 전화·안전Dream 링크 제공; FindUs는 제보 내용 미수집
- **완료 기준:** 안내 확인 가능; 모바일 전화·링크 정상 연결; 182 번호 표시

## 서비스 문의 (INQU)

### INQU-001 — 문의 작성 및 이메일 전달

- **관련 화면:** 문의하기
- **핵심 요구사항:** 문의 유형(비공개·정정·일반)과 내용 입력 후 운영 이메일 전달; 별도 관리 화면 없음
- **완료 기준:** 필수값 검증·전송 성공/실패 안내; 실패 시 입력 유지; 문의만으로 사건 정보 자동 변경 금지
- **미확정 / 검토 필요:** 수신 주소·회신 이메일 필수 여부 미정
