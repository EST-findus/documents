# 📚 FindUs 개인정보·윤리 정책 조사

## 1️⃣ 안전Dream OPEN API 이용약관

### ❓ 질문

**안전Dream Open API에서 제공받은 실종정보와 사진을 FindUs에서 어디까지 이용·가공·저장·공개할 수 있는가?**

### 📌 근거

#### 안전Dream OPEN API 이용약관 제5조

- 비상업적 목적으로 이용
- `[자료 출처: 경찰청]` 표시
- 정보의 왜곡·오인 금지
- 제공 정보의 임의 변조 금지
- 공공성 준수

#### 안전Dream OPEN API 이용약관 제7조

- API 이용만으로 제공 정보에 대한 저작권 또는 사용권을 취득하는 것은 아님

### 🔎 FindUs에서 의미하는 것

Open API를 통해 실종정보를 활용할 수는 있지만, 사진을 AI로 가공하여 새로운 이미지를 생성·저장·공개할 권리까지 자동으로 주어지는 것은 아니다.

### 🛠 FindUs 적용

- 경찰청 원본과 AI 생성 이미지를 명확히 구분
- 경찰청 자료에는 출처 표시
- AI 결과를 경찰청 공식 사진처럼 표현하지 않음
- AI 가공이 `임의 변조`에 해당하는지는 추가 확인

## 2️⃣ 개인정보 보호법

### ❓ 질문

**공개된 실종자 얼굴정보를 FindUs에서 수집·이용하고 AI 분석할 때 어떤 개인정보 보호 기준을 지켜야 하는가?**

### 📌 근거

#### 개인정보 보호법 제15조

- 개인정보를 수집·이용하려면 적법한 처리 근거가 필요

#### 개인정보 보호법 시행령 제18조 제3호

- 특정인을 알아보기 위해 기술적으로 생성한 생체 특징정보는 민감정보에 포함될 수 있음

#### 개인정보 보호법 제23조

- 민감정보는 별도 동의 또는 법령상 근거 등이 필요한 경우가 있음

#### 개인정보 보호법 제29조

- 개인정보의 유출·도난·변조 등을 막기 위한 안전조치 필요

### 🔎 FindUs에서 의미하는 것

FindUs는 안전Dream, 국가아동권리보장원 등에서 이미 공개된 실종자 정보를 사용한다.

다만 얼굴 사진에서 임베딩이나 특징값을 생성해 특정인을 식별하거나 비교하는 경우에는 단순한 사진 이용보다 더 주의가 필요하다.

### 🛠 FindUs 적용

- 공개된 실종자 정보만 사용
- 일반 사용자의 임의 얼굴 업로드 제한
- 실종자 탐색 목적 외 사용 제한
- 얼굴 임베딩 등 특징정보는 불필요하게 장기 저장하지 않음
- DB 및 로그 접근 권한 관리

## 3️⃣ 인공지능기본법

### ❓ 질문

**FindUs가 생성한 AI 예상 얼굴과 유사도 결과를 사용자에게 어떻게 표시하고 설명해야 하는가?**

### 📌 근거

#### 인공지능기본법 제3조

- AI의 안전성과 신뢰성을 고려
- 이용자가 AI 결과를 적절하게 이해할 수 있도록 하는 방향 필요

#### 인공지능기본법 제31조

- AI를 이용한 서비스라는 사실 고지
- AI 생성 결과물임을 표시
- 실제와 구분하기 어려운 이미지의 경우 AI 생성물임을 명확하게 표시

### 🔎 FindUs에서 의미하는 것

AI 예상 얼굴을 실제 현재 모습이나 경찰청 공식 사진처럼 보이게 해서는 안 된다.

유사도 역시 `정확도`나 `동일인 확률`처럼 오해할 수 있는 표현은 피해야 한다.

### 🛠 FindUs 적용

**경찰청 원본**

```
실종 당시 사진
자료 출처: 경찰청
```

**AI 생성 결과**

```
AI 생성 예상 현재 얼굴
실제 현재 모습과 다를 수 있습니다.
```

**유사도 안내**

```
얼굴 특징 유사도: 0.87
```

> 해당 값은 AI 모델이 비교한 얼굴 특징의 유사도를 의미하며, 실제 동일인일 확률을 의미하지 않습니다.
